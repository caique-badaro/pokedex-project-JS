<h3>Sobre o projeto</h3>

Este projeto consiste em uma Pokédex que consome dados da API pública de Pokémon e exibe os personagens da primeira geração. 
<br><br>
Na aplicação, é possível **ordenar, filtrar, pesquisar e favoritar seus pokémons preferidos,** além de utilizar o recurso “Surpreenda-me” para visualizar um pokémon aleatório. Também é possível conferir as habilidades de cada pokémon e descobrir em quais atributos eles mais se destacam.
