<h3>Sobre o projeto</h3>
<p>Esta aplicação simula uma Pokédex interativa que consome dados da API pública PokéAPI e renderiza cards dinamicamente no navegador.</p>
<p>O projeto foi desenvolvido como parte da evolução nos estudos de JavaScript moderno, com foco em:</p>

- [x] Consumo de APIs REST
- [x] Programação assíncrona
- [x] Manipulação do DOM
- [x] Arquitetura simples de front-end
- [x] Publicação com GitHub Pages

<br>
<h3>Arquitetura e conceitos aplicados</h3>
<p>Este projeto explora consumo de APIs, renderização dinâmica de interface com JavaScript e integração assíncrona utilizando:</p>

- [x] Fetch API para requisições HTTP
- [x] Promises para controle de fluxos assíncronos
- [x] Async/Await para escrita de código mais legível
- [x] Manipulação e tratamento de respostas JSON

<br>
<p><b>Fluxo simplificado:</b></p>

`Request → Fetch → Promise → Transformação → Renderização DOM`
